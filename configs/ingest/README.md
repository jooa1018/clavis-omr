# ingest

Owner: W5.

Constants and rule catalogs for ingest; no recognition rules added.

`limits.yaml` holds provisional operational allocation limits for bounded image
decoding. Bytes/pixels/count are resource units, not staff detection thresholds.
Protocol signatures, bit depths and EXIF mappings implement file formats; they
are not learned or switchable recognition rules. Future quality/geometry rules
must use a separate provisional staff-space/ratio registry and rule catalog.
