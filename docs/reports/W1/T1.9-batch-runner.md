## 7. 알려진 한계와 실패 사례 (숨기지 말 것)
Linux는 /proc/meminfo commit 정책과 RSS 표본 감시를 사용하며 Windows와 commit 의미가 완전히 같지는 않다.
Windows GetPerformanceInfo로 시스템 commit, EnumPageFiles로 페이지파일 실제 크기를 얻는다.
CPU/RSS/메모리는 100ms 표본이며 짧은 자식의 CPU 누락 가능. checkpoint는 작업 협조가 필요하다.
Torch/LightGBM/ORT 실제 학습 NOT_RUN(API 주입 mock 시험). 전체 시험 중 실제 인식 작업 없음.
근거: [GetPerformanceInfo](https://learn.microsoft.com/en-us/windows/win32/api/psapi/nf-psapi-getperformanceinfo),
[EnumPageFiles 구조체](https://learn.microsoft.com/en-us/windows/win32/api/psapi/ns-psapi-enum_page_file_information).
