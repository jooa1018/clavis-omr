## 7. 알려진 한계와 실패 사례 (숨기지 말 것)
Windows는 Job commit 상한과 RSS 감시, Linux는 affinity 상속·프로세스 그룹·RSS 표본 감시로 표본 사이 메모리 초과가 가능하다.
CPU/RSS는 100ms 표본이며 짧게 생긴 자식 CPU는 누락될 수 있다. 평균>8 CPU 경고를 보존한다.
설치되지 않은 Torch/LightGBM/ORT는 실제 학습 검증이 아닌 API 주입 mock 시험만 수행했다. 자동 설치하지 않는다.
체크포인트는 작업이 협조해야 하며 RNG/모델 상태를 저장할 책임은 호출 워커에게 있다. 예제는 정수 합계만 저장한다.
한 개 CPU만 사용 가능한 환경은 사용자용 CPU를 남길 수 없어 거부한다. 자동 OS 예약 등록은 하지 않았다.
JSONL 마지막 행은 비정상 디스크 종료 때 불완전할 수 있다. 상태 정본은 SQLite이며 긴급 중단 시 직전 checkpoint부터 재개한다.
