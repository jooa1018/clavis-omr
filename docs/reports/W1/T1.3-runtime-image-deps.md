## 7. 알려진 한계와 실패 사례 (숨기지 말 것)
최초 metadata 검사는 packaging/protobuf의 허용 라이선스 표기 차이로 실패했으며 원문 고지를 확인하고 정확한 표기를 추가했다.
lxml 6.1.3 Windows 휠은 libxml2 2.11.9/libxslt 1.1.45(MIT)를 보고한다. 그러나 공식 LICENSES.txt는 iconv LGPL 2.1도 명시한다.
공식 setupinfo.py는 Windows static 모드에서 iconv_a를 연결하며, 공식 wheel 설정은 static dependencies를 사용한다.
이것은 COMMON12의 "LGPL(정적 포함)" 금지와 충돌한다. Python 최상위 BSD 메타데이터만으로 통과 처리하지 않았다.
근거: [LICENSES.txt](https://github.com/lxml/lxml/blob/lxml-6.1.3/LICENSES.txt),
[정적 링크 설정](https://github.com/lxml/lxml/blob/lxml-6.1.3/setupinfo.py),
[휠 빌드 설정](https://github.com/lxml/lxml/blob/lxml-6.1.3/pyproject.toml).
해당 Windows wheel SHA-256/크기/출처와 검사한 LICENSES.txt SHA-256은 첨부 JSON에 기록했다.
