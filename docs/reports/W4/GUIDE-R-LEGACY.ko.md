# 기존 HarmonyMaker 자료 전달 안내 — R-LEGACY

기존 개발에 사용한 이미지와 당시의 독립 전사를 **PC 안의 비공개 폴더**에 모아 주세요.
예상 시간은 약 30분입니다. 이 자료는 회귀 시험에만 사용하고 일반화 성능 근거로 세지
않습니다. 새 찬양 악보 11쪽은 별도 안내의 R-TGT Dev 후보로 유지합니다.

## 1. 전달 대상

- HarmonyMaker 개발에 실제 사용했던 사용자 JPEG/PNG/PDF 원본.
- 기존 독립 A/B/C 전사와 자체 제작 6/8 사례가 있으면 그 원본 이미지·전사.
- 이미지별 정답 MusicXML 또는 MuseScore 원본(.mscz), 수기 전사 파일.
- 같은 이미지의 수정본·원본 구분과 어떤 전사가 최종인지 기록.
- 당시 확인한 사용 권리, 출처 기록. 모르는 항목은 ‘미상’이라고 적기.

없는 전사는 지금 새로 만들 필요가 없습니다. ‘전사 없음’으로 표시하면 W4가 남은
작업량을 확인합니다. HarmonyMaker 인식 결과만 있는 경우 ‘엔진 결과/독립 정답 아님’으로
표시해 주세요. 검증 없이 정답으로 등록하지 않습니다.

## 2. 저장 위치

저장소·OneDrive 등 자동 동기화 폴더 밖의 예시 위치:

```text
C:\Users\eccto\ClavisPrivate\
  legacy\legacy-001\original.jpg
  legacy\legacy-001\transcription.musicxml   (있으면)
  legacy\legacy-001\source.mscz              (있으면)
  legacy\legacy-001\intake.txt
```

여러 파일에 같은 익명 번호를 붙여 대응을 명확히 해 주세요. 파일명에 곡명을 새로 적을
필요는 없습니다. 원본 파일은 보존하고 이 폴더에는 복사본을 두어도 됩니다.
`intake.txt`에는 아래만 적으면 됩니다. JSON이나 해시는 W4가 접수 때 완성합니다.

```text
페이지 ID: legacy-001
같은 곡인 다른 페이지 ID / 조옮김·편곡 여부:
같은 촬영 세션 / 인쇄물인 다른 ID:
입력 경로: PDF / 스캔 / 휴대폰 사진 / 메신저 / 화면 캡처 / 미상
전사 파일과 상태: 독립 수기 / 엔진 초안 후 전부 대조 / 미검증 엔진 결과 / 없음
전사·검토 날짜(알면):
권리 근거: 자체 제작 / 공개 도메인 / 허락·라이선스 / 사용자 사용 권리 확인 / 미확인
권리 확인 기록의 위치:
이전 개발에 사용한 범위와 마지막 수정본:
```

## 3. W4에 알릴 내용

이 대화에는 **비공개 폴더 경로, 준비한 페이지 수, 전사 유무**만 알려 주세요.
이미지·가사·전사를 채팅에 첨부하거나 GitHub·CI·외부 서비스로 올리지 않습니다.
W4가 해당 Dev/legacy 폴더만 로컬에서 검증해 `legacy=true`, `contaminated=true`로
등록하고 부족한 항목을 정리하겠습니다. 보류/봉인용 자료는 전달 대상이 아닙니다.

GT 형식은 `clavis-gt-1`로 확정했습니다. 권리·이미지 대응·독립 전사 대조가 완료돼야
Dev에 들어가며 기존 파일이 있다는 사실만으로 정확한 정답으로 취급하지 않습니다.
