## 1. 미션

어떤 사진이 들어와도 **오선을 찾아 펴고, 정규 크기로 자른다.** 이것이 해상도 불변성의 첫 관문이다. 여기서 보표 하나를 놓치면 뒤 단계는 복구할 수 없다.

v1.1은 GPU를 쓰지 않는다. 오선 검출은 수십 년 검증된 **고전 방법을 먼저** 쓴다. 학습 모델은 고전 방법이 실사 Dev에서 부족하다는 수치가 나올 때만 추가하고, 그 경우에도 CPU에서 4시간 안에 학습되는 크기로 제한한다.

## 2. 범위

- 범위: S0(Ingest, 페이지 정규화, 품질 보고), S1(오선 기하, 스케일), S2(system, barline, 마디, 읽기 순서, 비오선 마스크), strip 추출과 **오선 제거 채널**, (P1) 품질 예측기
- 범위 밖: 기호 인식(W6), 텍스트(W7), 음악 해석(W8)

## 3. 작업 목록

### T5.1 Ingest와 페이지 정규화 (`src/clavis/ingest/`)

- 디코딩: PNG, JPEG, WebP, TIFF, BMP. PDF는 pypdfium2로 래스터화한다. 2단계 래스터화(낮은 dpi로 interline을 추정한 뒤 목표 interline이 되는 dpi로 다시 래스터화)를 쓴다.
- magic byte 확인, 크기·픽셀 수·페이지 수 한도, EXIF 방향, 16비트·알파·팔레트 정규화, 휘도 변환
- 사진이면 페이지 경계를 검출하고 원근을 보정한다(고전 CV). 조명을 평탄화한다(배경 추정 후 나누기). 자동 이진화 결과를 판단의 기본 입력으로 쓰지 않는다. 뒤 단계는 그레이스케일을 받는다.
- 모든 변환을 `original → processed` homography로 기록한다(CONTRACTS.md 2절).

### T5.2 품질 보고 (`QualityReport`)

- HarmonyMaker 호환 필드(흐림, 원근, 반사, 잘림 위험, 추정 staff space, 상태, 이유)와 확장 필드(대비, 잡음, JPEG 품질 추정, 페이지 안 interline 편차)
- 상태 임계값(pass, warn, retake)은 처음에는 잠정값이다. G2에서 W4의 해상도 곡선으로 다시 적합한다(헌장 A3). **목표는 interline 8 px까지 "사용 가능"으로 판정하는 것**이며, 근거는 곡선이다.

### T5.3 스케일 추정

- 세로 run-length 히스토그램으로 선 두께와 interline을 추정한다. 페이지를 타일로 나눠 국소 추정을 하므로 원근이 있어도 된다.
- 한 페이지에 크기가 다른 보표(작은 cue 보표 등)가 있을 수 있으므로 여러 가설을 둔다. 신뢰도를 함께 낸다.

### T5.4 오선 검출 (ADR-013)

- **고전 방법 v0**: 국소 기울기를 보정한 수평 투영, 열 띠마다 봉우리 찾기, 간격이 일정한 5선 묶기, 좌우 추적, 선마다 polyline(또는 스플라인) 적합. 곡률과 원근을 처리한다.
- 가사와 코드 줄, 덧줄, beam이 오선으로 오인되지 않게 한다. 6선 이상(타브)이나 1선(타악기)은 `ood`로 표시한다.
- **학습 보강(조건부)**: G1에서 고전 방법의 R-Dev 재현율이 기준(5절)에 못 미치면, 소형 U-Net(≤ 50만 파라미터, 128×128 조각)을 CPU로 학습해 오선 확률 지도를 보조 입력으로 쓴다. 학습은 W1 배치 실행기로 4시간 안에 끝나야 한다. 채택 여부는 ablation으로 정하고 ADR-013에 기록한다.

### T5.5 system 묶기와 읽기 순서

- 중괄호, 대괄호, system barline 연결, barline x좌표 정렬, 보표 간격으로 보표를 system으로 묶는다. 합창보처럼 barline이 보표 사이에서 끊긴 경우를 포함한다.
- 한 단 레이아웃만 지원한다. 여러 단이면 `CLAVIS_OOD/MULTI_COLUMN`으로 표시한다.

### T5.6 strip 추출 — **공용 함수**

- `extract_strip(page, staff_geometry, s_star, margins) -> (strip_image, mesh)`와 역대응 함수. CONTRACTS.md 2절과 2.1절을 따른다.
- **W6 학습 조각 샘플러와 엔진 추론이 같은 함수를 쓴다.** 빠르고(보표당 ≤ 30 ms, REF-LAPTOP), 결정적이어야 한다.
- **검출 오차 모델 공개**: SYN과 R-Dev에서 네 검출기의 오차 분포(선 위치, interline, 기울기, 끝점)를 측정해 `configs/geometry/jitter.yaml`로 공개한다. W6이 학습 조각을 만들 때 이 분포대로 흔든다. 게이트마다 갱신한다.

### T5.7 오선 제거 채널

- strip 좌표에서 오선은 정해진 행에 있다. 추정한 선 두께만큼 오선을 지우되, 선을 가로지르는 기호(stem, 음표 머리, beam)는 보존하는 제거 채널을 만든다. 세로 run 길이가 선 두께보다 긴 픽셀은 지우지 않는 식의 고전 기법을 쓴다.
- W6은 원본과 제거 채널을 **2채널**로 받는다. 제거 품질(선 잔여율, 기호 손상률)을 SYN 라벨로 재서 보고한다.

### T5.8 barline과 마디

- strip 위에서 세로선 후보를 찾고, 높이·두께·위치(staff-space 단위)와 소형 분류기(LightGBM, CPU)로 stem과 구분한다. 스타일(단일, 겹, 끝, 도돌이 점 포함)을 추정한다.
- system 안에서 보표 간 barline을 정렬하고, 마디 박스를 만든다.
- 최종 마디 구조는 W8이 W6 읽기 결과와 조정한다. 너는 **기하 근거와 신뢰도**를 제공한다.

### T5.9 비오선 마스크

보표 내부(오선 사이와 덧줄 영역)를 제외한 페이지 마스크와, 보표별 위·아래 텍스트 탐색 띠(staff-space 단위)를 W7에 준다.

### T5.10 (P1) 품질 예측기

품질 지표와 기하 신뢰도로 예상 교정 부담 구간(low, medium, high)을 예측하는 작은 모델(LightGBM)이다. W4의 Dev-Tune 결과로 적합하고 Dev-Check로 검증한다. 재촬영 안내 UX에 쓴다.

## 4. 첫 PR (착수 48시간 목표)

run-length interline 추정 + 투영 기반 고전 오선 검출 + `extract_strip` v0. W2 렌더 몇 장을 W3로 interline 16, 10, 8 px로 열화하고, 검출 결과와 strip을 겹쳐 그린 시험을 붙인다.

## 5. 수용 기준

| 지표 | G1 | G2 |
|---|---|---|
| 보표 검출 재현율 (SYN / R-Dev) | ≥ 99% / ≥ 97% | ≥ 99.5% / ≥ 98% |
| 보표 검출 정밀도 (SYN / R-Dev) | ≥ 99% / ≥ 97% | ≥ 99.5% / ≥ 98% |
| interline 상대 오차 중앙값 / p95 | ≤ 3% / ≤ 7% | ≤ 2% / ≤ 5% |
| dewarp 잔차(오선의 정규 행 이탈 RMS, staff-space) | ≤ 0.15 | ≤ 0.10 (SYN), ≤ 0.15 (R-PC 정합) |
| 오선 제거: 선 잔여율 / 기호 손상률 (SYN) | 보고 | ≤ 5% / ≤ 2% |
| barline F1 (SYN / R-Dev) | ≥ 97% / ≥ 93% | ≥ 98% / ≥ 95% |
| 지연 (S0–S2 + strip, REF-LAPTOP) | ≤ 5 s/쪽 | ≤ 3 s/쪽 |
| 학습 모델(있다면) 학습 시간 | ≤ 4 h CPU | ≤ 4 h CPU |

모든 지표를 해상도 구간별과 촬영 경로별로 보고한다. G1에서 고전 방법이 R-Dev 기준에 못 미치면 T5.4 학습 보강을 시작한다.

## 6. 이 역할의 함정

- **사진 한 장에 맞춘 임계값**이 가장 흔한 유혹이다. 모든 임계값은 staff-space 단위로 레지스트리에 두고, Dev-Tune 전체나 SYN으로 sweep해 정한다. 고전 방법일수록 규칙이 많으니 규칙 카탈로그(`configs/geometry/rules.yaml`)에 등록한다.
- 보표를 놓치는 것은 **조용한 대형 오류**다. 검출 신뢰도가 낮은 영역(오선 같은 패턴이 있지만 5선으로 묶이지 않는 곳)은 `OOD_REGION` 진단으로 올려 W8이 flag하게 한다.
- 원근 보정이 실패하면 이후 전부가 틀어진다. 실패를 감지해 보정 없이 진행하는 경로와 그 표시를 둔다.
- 학습 조각과 추론 strip이 다른 코드로 만들어지는 일이 없게 한다(T5.6).
