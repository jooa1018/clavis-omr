# ADR-010 — LeadGen 기본 분포

상태: **채택 (ACCEPTED), 선택 B**. 작성 W2. 결정권자 Orchestrator.
채택일: 2026-09-29. 근거: 사용자가 전달한 Orchestrator 판정.

## 문제와 선택지
선택 A는 모든 범주의 균등 분포, 선택 B는 흔한 범주 가중과 드문 범주
최소 출현이다. Orchestrator가 B와 아래 생산 프로필을 승인했다.

## 결정
- 장조:단조 = 3:1을 먼저 추출하고, 해당 모드 안에서 조를 추출한다.
- 장조 C, D, E, F, G, A, B♭, E♭, A♭, D♭는 가중치 2.
  단조 A, E, B, D, G, C, F#는 가중치 2. 나머지는 1. 각 모드 ±7 전부 포함.
- 초기 박자 4/4:3/4:6/8:2/4:12/8:2/2 = 4:2:3:1:1:1.
- 확률은 곡 비율과 해당 곡 안 비율을 별도로 보고한다.

| 요소 | 곡 비율 | 해당 곡 안 분모·목표 |
|---|---|---|
| 못갖춘마디 | 30% | 발생 곡 수와 못갖춘마디 수 보고 |
| 곡 중 조·박자 변경 | 5% | 발생 곡 수와 변경 이벤트 수 보고 |
| 도돌이·볼타·진행 문구 중 하나 이상 | 20% | 발생 곡 수와 종류별 이벤트 수 보고 |
| 리듬 슬래시 | 10% | 그 곡 마디의 10–40% |
| 2성부 | 10% | 그 곡 마디의 20–50% |
| 셋잇단 | 15% | 그 곡 마디의 10–30%에 셋잇단 1개 이상 |
| 꾸밈음 | 10% | 그 곡 음표의 2–5% |

- 1만 곡 블록마다 P0 요소별 곡 비율 ≥1%, 인스턴스 ≥500을 모두 검사한다.
- 남은 길이를 채우는 탐욕 생성은 금지한다. 박자별 박 묶음 단위로 생성한다.
- 목표 음가 분포는 **PDMX 학습 하위집합의 박자별 집계 분포**다(헌장 A5)。
  실제 집계가 없으면 임의 분포를 PDMX 분포로 대체하지 않는다.
- 32분음표와 겹점은 각각 음표의 ≥0.5%. 목표와의 KL 발산을 보고한다.
- W4 지문 필터 연결 전까지 학습 편입은 계속 차단한다.

## 개발 코어와 검증 범위
개발 코어 PR #9의 `leadgen-development.yaml`은 파서·시간축·시드 검사만을
위한 과거 실험 설정이며 채택된 생산 분포가 아니다. 기존 남은 길이 기반
리듬은 생산에서 재사용하지 않는다. 90개 조·박자 검사 근거는
`docs/reports/W2/leadgen-development-validation.json`에 있다.
생산 구현·1만 곡 블록·실제 PDMX KL 검증 완료를 뜻하는 채택은 아니다.

## 되돌릴 조건과 미해결 상류
P0 누락, 시간합 오류, 희귀 음가 하한 미달, 편중을 계측해 실패를 보고한다.
목표 수치나 분모를 자체 변경하지 않고 Orchestrator에게 에스컬레이션한다.
PDMX 항목별 권리 확인과 학습 분할 집계, W4 지문 필터는 별도 선행조건이다.
개별 평가 곡·실패 이미지로 분포를 정하지 않는다. 계약 변경은 없다.
