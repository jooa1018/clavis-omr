# ADR-010 — LeadGen 기본 분포 (초안, 미채택)

상태: PROPOSED. 작성 W2. 결정권자 Orchestrator. 날짜 2026-09-29.

## 문제와 선택지
W2 지시서는 ±7 조표, 6개 박자, 4/8마디, 성부 음역, 여러 기보 요소의
목표 발생률을 지정하지만 조·박자·음가의 정확한 가중치는 아직 정하지 않았다.
선택 A: 모든 범주 균등(분포 확인에 유리). 선택 B: 흔한 조·박자·음가에
가중치 + 드문 범주 최소 출현을 강제(지시서 목표). 학습 기본값은 B를 제안한다.

## 제안 (승인 전 적용 금지)
- major/minor를 따로 기록하고, 명시된 흔한 조군은 나머지보다 2배 가중.
- 초기 박자 비율 4/4:3/4:6/8:2/4:12/8:2/2 = 4:2:3:1:1:1.
- pickup 30%, 곡 중 조·박자 변경 5%, 진행 문구 20%, tuplet 5%, grace 2%,
  slash 10%, 2성부 10%는 지시서 값 유지. 각 비율의 분모(곡/이벤트)를
  확정하고 이벤트 비율과 곡 출현율을 따로 보고하는 것이 필요하다.
- 가중치만으로 모든 P0 1%를 보장하지 않으므로 생성 후 분포 보고서를 보고
  다음 생성 블록을 보강한다. 평가 곡·개별 실패 이미지를 선택 기준으로 쓰지 않는다.

## 현재 실험 코드와 근거
`leadgen-development.yaml`은 파서·시간축·시드 시험용이며 학습 기본값이 아니다.
현재 API는 purpose=development만 받고 출력은 work/로 제한한다.
첫 구현은 단일 성부, 조표, 박자, 세 음자리표, 온음표–32분음표, 점·쉼표,
quarter pickup, 제목·템포다. 마디 리듬은 정수 시간축의 도달 가능한 길이만
먼저 구성한다. 원본 악보를 고치거나 음표를 추정해 채우는 인식기가 아니다.
독립 파싱·시간합 검사 근거는 W2 LeadGen 착수 보고서에 기록한다.

## 승인 요청과 되돌릴 조건
생산용 분포 채택과 확률 분모 확정은 Orchestrator 판정이 필요하다.
그 전에는 개발 코어 검사까지만 수행하며 학습 데이터 편입·양산을 하지 않는다.
P0 누락, 특정 범주의 쏠림, 가중치 때문에 유효 마디를 만들 수 없는 사례가
생기면 프로필을 되돌리고 일반 범주 수준에서 수정·비교한다. W4 지문 필터는
어느 선택에서도 필수이며 미연결 시 학습 편입은 차단한다.
