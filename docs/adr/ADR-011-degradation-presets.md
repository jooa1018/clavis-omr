# ADR-011 — 열화 계열과 촬영 경로 분포

상태: **DRAFT / Orchestrator 결정 요청**. W3 구현은 실험용이며 학습 기본값 채택을 뜻하지 않는다.
작성: W3, 2026-09-29. 근거: W3_DEGRADATION T3.2–T3.6, 일반화 헌장 A5/F8.

## 문제와 선택지
첫 PR은 3계열(기하·해상도·압축)이다. 최소 8계열과 12개 촬영 경로를
실사 복사 없이 제공하면서 라벨 정확성과 CPU 실행 예산을 유지해야 한다.
실사 집계 통계가 아직 없어 현실성이 검증된 분포를 선택할 수 없다.

1. **제안 A / 현재 실험 구현**: 9계열의 해석적 연산과 YAML 범위로 모든 경로를
   구성한다. `experimental-unfitted` 표시를 유지한다. 매개변수 및 RNG 상태를
   기록하여 replay한다. 실제 학습 분포 채택은 Orchestrator 판정 후 한다.
2. B: W4 집계가 준비될 때까지 프리셋 구현을 보류한다. 검증 근거는 강해지지만
   하류 합성 학습·변환 시험 연결이 지연된다.
3. C: 프리셋 이름을 카메라/앱의 정확한 모사로 간주한다. 보정 근거가 없어 제안하지 않는다.

## 제안 A의 구체적 범위
- 기하: 회전·평면 pinhole 원근·부드러운 수직 sine paper wave.
- 조명: 선형 그라데이션·비네팅·매끄러운 그림자.
- 광학: Gaussian PSF 흐림. 해상도: 목표 interline 축소. 압축: 반복 JPEG.
- 센서: Gaussian 잡음. 스캔: 이진화·침식/팽창 복사기 효과.
- 종이: 저주파 절차적 음영. 화면: 주기적 간섭 패턴.
- 범위·단위·예산은 `configs/degrade/presets.yaml`에 기록했다. 모든 이미지 효과는
  기본 수학적 변환이고 렌더 내용/ID/페이지 번호에 따른 판단은 없다.
- `scan-150/300`은 실제 DPI 보장을, `messenger-kakao`는 앱 내부 압축 규칙 보장을
  하지 않는다. 모두 지시서에 지정된 경로 이름의 스트레스 조합이다.

## 목표 interline 분포의 해석 — 판정 필요
지시서의 40/35/20/5%와 7–10/10–14/14–24/24+ 구간을 그대로 사용한다.
구간 내에서는 uniform을 제안한다. 24+의 상한은 해당 시점 합성 렌더의 interline이다.
깨끗한 렌더보다 확대하지 않는다. 모든 구간을 지원할 수 없는 입력(기하 후 중앙값 <24)
은 **거부**하며, 조용한 clamp/재추출/가중치 재정규화로 저해상도 분포를 바꾸지 않는다.
고정된 24+ 상한이 필요하다면 Orchestrator가 정할 수 있다. 현재 코드/샘플은
단순히 이 제안의 검토용 결과이며 최종 기본 분포를 자체 채택하지 않았다.

## 비선형 라벨 처리 — 내부 구현
`phone-curl`은 원통형 광학의 정밀 모델이 아니라 약한 종이 휨 근사다.
`y'=y+A sin(ωx+φ)`의 역함수로 래스터를 샘플링하고 점/마스크를 같은 맵으로 변환한다.
박스는 변의 내부 sine 극값까지 포함한다. 폴리라인 분할은 선형 보간 오차식
`max|y''| Δx²/8`로 결정하여 출력 오차 설정을 지킨다. 접선은 Jacobian으로 옮긴다.
비선형 파이프라인은 `matrix: null`을 반환하며 `operations` 순차 trace가 근거다.
이는 W3 내부 컨테이너/trace뿐이고 CONTRACTS의 엔진 프레임 계약 변경이 아니다.
W2 SVG staff-local audit를 전역 페이지 라벨로 임의 해석하거나 공개 계약으로 승격하지 않는다.

## 검증·되돌릴 조건
자동 합성 시험, 1·4스레드 재현성, inverse mask oracle, 소규모 CPU 측정을 보고서에 첨부한다.
실사 KS/분위수 및 도메인 분류기 AUC는 **NOT_RUN**이다. 실사 통계는 W4 집계만 받는다.
W4 집계에 비추어 범위가 부적합하거나 변환 라벨 오차가 기준을 넘으면 해당 범위/연산을
수정·비활성화한다. 범위 변경은 전체 합성 슬라이스와 향후 Dev 검증으로 재확인한다.
성능 미달을 이유로 어려운 경로나 샘플을 숨기지 않는다. 실제 원통 모델, mesh 캐시,
추가 광학·압축 연산은 이 근사를 사실적인 모델로 포장하지 않고 후속 검토한다.

## 필요한 Orchestrator 결정
1. 실험 프리셋의 구간 내 uniform 및 24+ 상한/저해상도 입력 거부 정책을 채택할지.
2. phone-curl의 초기 근사를 검토용으로 유지하고 W4 통계 수신 후 보정할지.
3. 학습 기본값 채택 전 요구할 현실성/성능 근거. 본 초안은 G1 승인 요청이 아니다.
